# pracricas-HTML-y-CSS3
Este repositorio contiene una serie de prácticas iniciales de HTML y CSS, realizadas durante mis primeros pasos en el desarrollo web. Incluye ejercicios básicos enfocados en estructura, etiquetas fundamentales, estilos esenciales y conceptos clave del diseño web moderno.

Aunque son proyectos sencillos, representan el inicio de mi aprendizaje y la base sobre la cual he construido habilidades más avanzadas en frontend.
